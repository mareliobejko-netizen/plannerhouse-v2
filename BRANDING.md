# La Dogana branding

This build standardises the public-facing identity as **La Dogana Guest Portal**.

- Browser/app title: La Dogana Guest Portal
- Browser description and manifest added
- Theme colour: #304030
- Background colour: #F7F5F0
- New LD monogram favicon
- Guest-facing top bars labelled Guest Portal
- Admin links use Guest portal rather than Client area
- Existing La Dogana logo remains the primary visual mark

PlannerHouse may remain the internal repository/project name, but it is no longer used as the customer-facing brand.
